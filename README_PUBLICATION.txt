PUBLICATION GITHUB PAGES

1. Ouvrir https://github.com/jouvensgabrieljouvens-design/decouverte-verite
2. Sauvegarder les fichiers actuels avant de modifier index.html.
3. Envoyer TOUS les fichiers de ce dossier à la racine du dépôt (branche publiée par GitHub Pages).
4. Vérifier dans Settings > Pages que le site utilise la bonne branche et le bon dossier.
5. Tester la page et les deux téléchargements.

MISE À JOUR DES LIVRES
Remplacer le PDF français ou anglais en gardant exactement le même nom de fichier. Le lien et le QR code ne changent pas.

ATTENTION : le site fourni remplace index.html et peut modifier le contenu actuel de la page. Vérifier le dépôt avant publication.
Les éditions sont des versions de travail, et non une certification de vérification intégrale.
